# Wedding invites

Static wedding invitation pages, served at https://invite.tettesthub.in (GitHub Pages).
Each invitation lives in its own folder, e.g. `durgesh-sanjana-vivah-video/`.
Pages are `noindex`; only people with the link see them.

The old Mukesh Dahiya education site that used to be here is saved in the
`backup-mukesh-site` branch.
